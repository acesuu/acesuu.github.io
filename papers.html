A Benchmark Dataset and LLMs Comparison for NFR Classification with Explainable AI 2025 Oct

Extends an existing non-functional requirements dataset with NFRs collected from project charters and open-source software documentation, organized into sub-classes. It compares RoBERTa, CodeBERT, Gemma-2, Phi-3, Mistral-8B, and Llama-3.1-8B on NFR classification and uses LIME to explain their predictions. Gemma-2 performed best (F1 0.88), with Phi-3 close behind (F1 0.86, highest LIME hit score).

Analysis on LLMs Performance for Code Summarization 2024 Dec

A comparative analysis of open-source LLMs (LLaMA-3, Phi-3, Mistral, and Gemma) for generating natural-language summaries of source code, evaluated with BLEU and ROUGE. It identifies each model's strengths and weaknesses for code summarization in software development and maintenance.
